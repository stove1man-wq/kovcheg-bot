# kovcheg-bot — бот канала «Системы Ковчег»

Единая точка входа из постов канала, сайта и статей. За ~45 секунд определяет, кто пришёл (человек или бизнес) и что интересно
(Барабашка, Ковчег Документы, Память, Дом, Шлюз), записывает в лист раннего доступа, приглашает на созвон или принимает
заявку компании. Сценарий: `docs/ideas/marketing/Kovcheg_Systems_Bot_Funnel.pdf` в репозитории Barabashka.

## Что умеет
- Согласие на обработку персональных данных **до** сохранения чего-либо. Без согласия ничего не пишется.
- Ветки «человек» и «бизнес», теги `b2c_*`, `pro_docs`, `b2b_gateway`, источник перехода из ссылки `t.me/бот?start=site_barabashka`.
- Заявки: сохраняются в базе, уходят письмом на почту (если настроена), видны администратору по `/apps`.
- `/delete` — удалить все свои данные, `/privacy` — политика, `/stats` и `/apps` — только для администратора.

## Запуск (Windows, один раз)
1. Создайте бота у @BotFather, получите токен. **Токен никому не показывайте и в репозиторий не кладите.**
2. В папке проекта:
   ```
   py -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   copy .env.example .env
   ```
3. Откройте `.env` в блокноте, впишите `BOT_TOKEN`, свой `ADMIN_ID` (узнать у бота @userinfobot), `POLICY_URL`, при желании почту.
4. Запуск: `.venv\Scripts\python -m kovcheg_bot`

Для работы 24/7 бот должен жить на сервере (VPS), а не на ноутбуке. Есть `Dockerfile`:
`docker build -t kovcheg-bot .` и `docker run -d --restart=always --env-file .env -v kovcheg-data:/data kovcheg-bot`.

## Перед публикацией (обязательно)
- Страница политики обработки персональных данных на сайте, её адрес в `POLICY_URL`.
- Данные граждан РФ хранить на сервере в России (152-ФЗ); ИП должен быть зарегистрирован как оператор персональных данных.
- Тексты в `kovcheg_bot/texts.py`: проверьте обещания (например, условия VIP-доступа) прежде, чем выпускать бота.
- MAX: после регистрации ИП и проверки на business.max.ru добавляется второй адаптер на том же ядре (`flow.py`).

## Устройство
`flow.py` — логика диалога без привязки к мессенджеру (тесты: `python -m pytest`); `telegram_app.py` — адаптер Telegram;
`storage.py` — SQLite; `mailer.py` — письма; `texts.py` — все тексты и список продуктов.
